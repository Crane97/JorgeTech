# STEP 3 - Site architecture

## Visitor path (2–4 minutes)

1. **Hero** - Name as brand, one positioning line, two CTAs (Selected work / Contact), dominant portrait/product visual.
2. **Selected Projects (home)** - Compact preview of the three latest builds (image + short copy) with CTA to the full archive.
3. **All projects (`/projects`)** - On-page case studies one-by-one. Media leads; structured Problem / Solution / Architecture / Technologies / Results from existing detail content.
4. **Professional Experience** - Timeline of roles with existing bullets.
5. **Technology Stack** - Aggregated from real project/experience technologies, grouped for scanning.
6. **About Me** - Personal story + boxing gallery (existing assets/copy).
7. **Résumé** - Scannable Experience + Education + Courses + languages (existing content).
8. **Contact** - Single contact intent: form that prepares mailto + social links.

## Why each change improves the experience

| Change | Why |
| --- | --- |
| Short project preview on home | Keeps the 2–4 minute scan fast without losing proof |
| Full case studies on `/projects` | Depth on demand without burying work in modals |
| Case-study structure | Communicates engineering judgment, not just a title list |
| Light product theme | Reads as SaaS/product craft (Stripe/Linear/Vercel), not agency mood board |
| Geist type system | Signals contemporary product engineering taste |
| Horizontal sticky nav | Familiar product pattern; faster wayfinding |
| Stack section | Recruiters filter by tech in seconds |
| Résumé section | Replaces hunting through multiple CV-like blocks |
| Restrained motion | Credibility over spectacle; Apple-like presence |

## Layout families (no repetition)

1. Hero - asymmetric split / full-bleed visual plane
2. Home projects - compact media/text rows + archive CTA
3. `/projects` - alternating media/text case studies
4. Experience - vertical timeline with hairlines
5. Stack - grouped mono chips in columns
6. About - editorial text + horizontal image strip
7. Résumé - two-column dense scannable document
8. Contact - form + sparse meta

## Preserved

All project copy, experience, education, courses, about/boxing content, screenshots, photos, logos, EN/ES/FR localization, mailto contact.
